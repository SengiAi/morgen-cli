# Morgen API

Build powerful calendar and task integrations with a unified API that works across Google Calendar, Microsoft 365, iCloud, and more.

🚀

Thinking of integrating Morgen into **your product or service**? Tell us
more about your API use case.

[Contact us](mailto:connect@morgen.so?body=Hi,%20I%27m%20interested%20in%20integrating%20the%20Morgen%20API%20into%20my%20product...%20(please%20provide%20details))

⚠️

The Morgen API is in early access. While we strive not to make breaking changes within each major version, new fields may be added at any time without prior notice. Make sure your code handles unknown fields gracefully. We recommend following our [changelog](https://docs.morgen.so/changelog) for updates.

## What can you build? [Permalink for this section](https://docs.morgen.so/\#what-can-you-build)

The Morgen API provides a unified interface to interact with calendars and tasks across multiple providers. Here’s what you can do:

### 📅 Calendar Events [Permalink for this section](https://docs.morgen.so/\#-calendar-events)

Create, read, update, and delete events across all connected calendar accounts. The API supports:

- **Recurring events** with flexible recurrence rules
- **Attendees and invitations** with participation status
- **Virtual meeting rooms** (Google Meet, Microsoft Teams, Zoom, Webex)
- **Reminders and alerts** customization
- **All-day and timed events** with timezone support

[Learn more about Events →](https://docs.morgen.so/events)

### ✅ Tasks [Permalink for this section](https://docs.morgen.so/\#-tasks)

Manage Morgen tasks programmatically—ideal for automations and integrations:

- Create, update, and organize tasks
- Set due dates, priorities, and estimated durations
- Build subtask hierarchies
- Mark tasks as complete or reopen them

[Learn more about Tasks →](https://docs.morgen.so/tasks)

### 🔗 Integrations [Permalink for this section](https://docs.morgen.so/\#-integrations)

Access all calendar accounts connected to a user’s Morgen account:

- **Google Calendar** and **Microsoft 365**
- **iCloud**, **Fastmail**, and **CalDAV** providers
- **Calendar feeds** (read-only subscriptions)
- **Video conferencing** services (Zoom, Webex)

[Learn more about Integrations →](https://docs.morgen.so/integrations)

### 📆 Calendars [Permalink for this section](https://docs.morgen.so/\#-calendars)

List and manage calendars across all connected accounts, including calendar metadata and user permissions.

[Learn more about Calendars →](https://docs.morgen.so/calendars)

## Getting Started [Permalink for this section](https://docs.morgen.so/\#getting-started)

1. **Get your API key** — Sign up at [platform.morgen.so](https://platform.morgen.so/) and navigate to the Developers API page
2. **Connect your calendars** — Use the Morgen app or platform to connect your calendar accounts
3. **Start building** — Use your API key to authenticate requests

[Get your API key →](https://docs.morgen.so/authentication)
