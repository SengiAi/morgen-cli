# Morgen API Introduction

Morgen API allows developers to build features that interact with calendars hosted on different providers, including Google, Microsoft, Apple and other CalDAV providers.

## Authentication [Permalink for this section](https://docs.morgen.so/introduction\#authentication)

Before you can start using Morgen API, you need to get an API key. Learn more about [authentication](https://docs.morgen.so/authentication).
