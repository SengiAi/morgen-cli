# Morgen API Authentication

## Get your API key [Permalink for this section](https://docs.morgen.so/authentication\#get-your-api-key)

### Sign in to Morgen platform [Permalink for this section](https://docs.morgen.so/authentication\#sign-in-to-morgen-platform)

Create a new account or sign in to [Morgen platform](https://platform.morgen.so/).
If you already have a Morgen account, you can use it to sign in to Morgen platform.

### Get your API key [Permalink for this section](https://docs.morgen.so/authentication\#get-your-api-key-1)

You can get your API key navigating to [Developers API](https://platform.morgen.so/developers-api) page.

### Copy your API key [Permalink for this section](https://docs.morgen.so/authentication\#copy-your-api-key)

In the page you will be able to copy your API key, keep it safe.

If you believe your API key has been leaked, you can regenerate it.
